# Power BI PR1 - Superstore Sales Analysis

## Project Overview
An interactive Power BI dashboard built using the Sample Superstore dataset.

## Objectives
- Analyze sales and profit performance.
- Identify top-performing product categories.
- Understand regional sales distribution.
- Analyze customer segments.
- Track business performance using KPIs.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Project Structure
- data: Dataset and processed files
- documentation: Project documentation
- reports: Dashboard page descriptions
- dax: DAX calculations
- theme: Report themes
- screenshots: Dashboard screenshots
- queries: Power Query scripts
- resources: Supporting materials
